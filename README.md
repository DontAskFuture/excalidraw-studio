# Excalidraw Studio (Local Rust Server — No Docker Required)

A self-hosted Excalidraw workspace backed by a lightweight native **Rust (`Axum`) server** ([`rust-server/`](rust-server)) and **`studio-ui/`** wrapper ([`studio-ui/`](studio-ui)). Runs directly on your machine with **no Docker container** and **no runtime Node.js server**.

## Quick Start (Without Docker)

### Prerequisites (for building from source)
- **Rust** (`cargo` / `rustc` via [rustup.rs](https://rustup.rs))
- **Node.js >= 18** + **npm** (or **Yarn**) — used only when building the static UI bundle into `rust-server/dist`

### 1. Start with one command
From the repository root:
```bash
./start-studio.sh
# or:
npm run studio:start
```
On first run (or whenever assets/binary are missing), `start-studio.sh` installs JS dependencies if needed, bundles [`studio-ui/`](studio-ui) into `rust-server/dist`, compiles [`rust-server/`](rust-server) in `--release` mode, and starts the app at:

- **App URL:** `http://127.0.0.1:3001`
- **Default local data folder:** `./rust-server/data`

### 2. Custom port / host / save folder
```bash
./start-studio.sh --port 4000 --data-dir ~/Documents/ExcalidrawWorkspace
```
Or force a clean rebuild after modifying UI or Rust source:
```bash
./start-studio.sh --build        # rebuild UI + Rust binary and start
./start-studio.sh --build-only   # rebuild only (same as: npm run studio:build)
```

### 3. Run standalone prebuilt binary directly (no Node.js required)
Once built, you can launch the Rust server binary directly with environment variables:
```bash
cd rust-server
HOST=127.0.0.1 PORT=3001 ./target/release/excalidraw-rust-server
```
Supported environment variables:
- `HOST` (default: `127.0.0.1`)
- `PORT` (default: `3001`)
- `EXCALIDRAW_DATA_DIR` (default: `./rust-server/data`)
- `EXCALIDRAW_DIST_DIR` (default: `./rust-server/dist`)

## Included Studio Features

- **Project Organization & Atomic Local Autosave**
  - Group diagrams into projects and switch/re-enter diagrams seamlessly.
  - Every edit autosaves atomically to `<data-dir>/projects/<project>/scenes/<scene>.excalidraw` with embedded images stored once per project.
  - Use **`Copy`**, **`Finder`**, or **`Change…`** in the sidebar (`Local Autosave` card) or `MainMenu` to copy, reveal, or relocate the default save directory (supports `~/...`, Finder folder browsing, and non-destructive project copying).

- **Two-Way Mermaid (`.mmd`) & PlantUML (`.puml`) Sync**
  - Click **`⇄ Mermaid (.mmd)`** or **`⇄ PlantUML (.puml)`** in the left sidebar or top-right toolbar to open the split-pane code editor.
  - Supports **Flowcharts / Component / Architecture** diagrams and **Sequence** diagrams, converting Canvas ↔ Code live while preserving custom node colors and freehand sketches.
  - Companion `<scene>.mmd` and `<scene>.puml` files are saved alongside `<scene>.excalidraw`; external disk edits to `.mmd` or `.puml` are detected and synced automatically when reopening a scene.

## Running Tests

```bash
npm run studio:test
```
This runs:
- Frontend bidirectional Mermaid / PlantUML sync tests (`studio-ui/src/__tests__/diagramSync.test.ts` via Vitest)
- Rust backend unit & integration tests (`rust-server` via `cargo test`)

## Features

The Excalidraw editor (npm package) supports:

- 💯&nbsp;Free & open-source.
- 🎨&nbsp;Infinite, canvas-based whiteboard.
- ✍️&nbsp;Hand-drawn like style.
- 🌓&nbsp;Dark mode.
- 🏗️&nbsp;Customizable.
- 📷&nbsp;Image support.
- 😀&nbsp;Shape libraries support.
- 🌐&nbsp;Localization (i18n) support.
- 🖼️&nbsp;Export to PNG, SVG & clipboard.
- 💾&nbsp;Open format - export drawings as an `.excalidraw` json file.
- ⚒️&nbsp;Wide range of tools - rectangle, circle, diamond, arrow, line, free-draw, eraser...
- ➡️&nbsp;Arrow-binding & labeled arrows.
- 🔙&nbsp;Undo / Redo.
- 🔍&nbsp;Zoom and panning support.

## Excalidraw.com

The app hosted at [excalidraw.com](https://excalidraw.com) is a minimal showcase of what you can build with Excalidraw. Its [source code](https://github.com/excalidraw/excalidraw/tree/master/excalidraw-app) is part of this repository as well, and the app features:

- 📡&nbsp;PWA support (works offline).
- 🤼&nbsp;Real-time collaboration.
- 🔒&nbsp;End-to-end encryption.
- 💾&nbsp;Local-first support (autosaves to the browser).
- 🔗&nbsp;Shareable links (export to a readonly link you can share with others).

We'll be adding these features as drop-in plugins for the npm package in the future.

## Quick start

**Note:** following instructions are for installing the Excalidraw [npm package](https://www.npmjs.com/package/@excalidraw/excalidraw) when integrating Excalidraw into your own app. To run the repository locally for development, please refer to our [Development Guide](https://docs.excalidraw.com/docs/introduction/development).

Use `npm` or `yarn` to install the package.

```bash
npm install react react-dom @excalidraw/excalidraw
# or
yarn add react react-dom @excalidraw/excalidraw
```

Check out our [documentation](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/installation) for more details!
